JAVA BLISS COFFEE SHOP WEBSITE
================================

PROJECT FILES
- index.html       Home page
- about.html       About page
- services.html    Services page
- contact.html     Contact page with a demonstration form
- style.css        Website styling and responsive layout
- script.js        Mobile navigation and form demonstration
- images/          Home page coffee photograph

HOW TO OPEN
1. Extract JavaBliss_Professional.zip.
2. Open the extracted JavaBliss_Professional folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Use the navigation links to visit all four pages.

USING XAMPP
1. Copy the JavaBliss_Professional folder into C:\xampp\htdocs\
2. Start Apache in the XAMPP Control Panel.
3. Visit http://localhost/JavaBliss_Professional/

IMPORTANT
The contact form is a front-end demonstration. It validates required fields
and displays a confirmation message, but it does not send or store email.
To receive real messages, connect it to a secure server-side PHP handler.

The business contact information is sample content. Replace it with the
actual business details before submitting or publishing.
